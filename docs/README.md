# Documentation index

This directory holds the explanations that used to live as long comments in
the integration's code. Each file owns one kind of fact so a reader (human
or agent) knows where to look.

- [design.md](design.md): architecture and rationale for how the connection,
  entities, and config flow are structured.
- [protocol.md](protocol.md): HomeKit Accessory Protocol (HAP) and device
  facts, verified versus unverified, including vendor-specific quirks.
- [decisions.md](decisions.md): dated decisions, including the bug a
  workaround exists for.
- [operations.md](operations.md): running the test suite, including a
  platform-specific quirk that affects how it's configured.
- [device-notes.md](device-notes.md): per-device notes from real HA
  diagnostics exports for specific paired accessories.
